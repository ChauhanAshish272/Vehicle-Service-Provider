# 🚗 Vehicle Service Provider

A web-based application that allows users to book vehicle service appointments online. The system manages customer data, service requests, and admin controls using a PHP-MySQL backend.

## 📌 Features

- User registration and login
- Online booking for vehicle servicing
- Admin dashboard to manage bookings and services
- Service request history for users
- Basic validation for user inputs

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
